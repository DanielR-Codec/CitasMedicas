# Sistema de Gestion de Citas Clinicas

Bienvenido a la primera parte de este **Sistema de Gestión de Citas Clinicas**. 

Este proyecto ayuda a gestionar las citas medicas de una mejor manera y no a lapiz y papel sino de forma tecnologica con facilidades que permiten que todo sea mas rapido y eficiente.

## ¿Qué puedes hacer con esta app?

*    **Gestion de Personal:** Registra especialidades medicas y a los doctores asignados a cada una.
*    **Control de Pacientes:** Mantén un directorio organizado con los datos de contacto.
*    **Agenda Dinámica:** Una interfaz visual en forma de cuadrícula (de 09:00 a 20:00) que dibuja tarjetas de colores para cada cita agendada.
*    **Flexibilidad total:** ¿Un paciente no puede asistir? Haz clic en la tarjeta de su cita para reprogramarla a una nueva fecha o cancelarla.
*    **Recordatorios integrados:** El sistema está preparado de forma modular para enviar recordatorios por correo a los pacientes una vez que su cita es confirmada (solo simulado por el momento).
